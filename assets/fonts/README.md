# Bundled fonts

This directory contains only the weights and character subsets used by Local Dev Manager:

- Tajawal Arabic and Latin, weights 400, 500, and 700, from `@fontsource/tajawal@5.3.0`.
- IBM Plex Mono Latin, weights 400 and 500, from `@fontsource/ibm-plex-mono@5.3.0`.

Both packages were obtained from the official npm registry. Their font files are licensed under SIL Open Font License 1.1; the original license files are included here. This font license is separate from the application's MIT license.
