# Code of Conduct

We want project discussion to be useful and respectful. Be considerate of different experience levels, assume good faith, and focus criticism on ideas and code. Harassment, discrimination, threats, doxxing, and sharing another person's private information are not welcome.

This applies to issues, pull requests, discussions, and other project spaces. Maintainers may edit or remove harmful content and limit participation when necessary. To report a conduct concern, use a private channel available through the repository owner's GitHub profile. Do not include sensitive personal details in a public issue.
