# Local Dev Manager v1.0.0

## English

The first public release for Windows x64. Manage local Node.js projects from one desktop app: start/stop/restart, port checks, per-project logs, package manager detection, optional autostart and bounded crash restart, English/Arabic UI, and system tray controls. Download `Local Dev Manager Setup 1.0.0.exe` and compare its SHA-256 with `SHA256SUMS.txt` if desired. `latest.yml` and the blockmap support packaged-app updates. The installer may show a Windows SmartScreen warning because it has no established trusted code-signing reputation. Node.js/npm are required for managed projects.

## العربية

الإصدار العام الأول لـ Windows x64. يدير مشاريع Node.js المحلية من نافذة واحدة: التشغيل والإيقاف وإعادة التشغيل، فحص المنافذ، سجلات منفصلة، اكتشاف مدير الحزم، التشغيل التلقائي وإعادة التشغيل المحدودة عند الانهيار، واجهة عربية/إنجليزية، وصينية النظام. نزّل `Local Dev Manager Setup 1.0.0.exe` وقارن SHA-256 مع `SHA256SUMS.txt` عند الحاجة. يدعم `latest.yml` وملف blockmap تحديثات التطبيق المثبّت. قد يظهر تحذير Windows SmartScreen لعدم وجود سمعة توقيع برمجي موثوقة بعد. تحتاج مشاريعك إلى Node.js/npm.

## 简体中文

首个公开版本，面向 Windows x64。在一个桌面应用中管理本地 Node.js 项目：启动、停止、重启、端口检查、独立日志、包管理器识别、可选自动启动和有限次数的崩溃重启、英语/阿拉伯语界面及系统托盘。下载 `Local Dev Manager Setup 1.0.0.exe`，如需验证请对照 `SHA256SUMS.txt` 中的 SHA-256。`latest.yml` 和 blockmap 用于已安装应用的更新。安装包尚无成熟的可信代码签名信誉，因此 Windows SmartScreen 可能显示警告。管理项目需要 Node.js/npm。
