# Local Dev Manager v1.0.0 — revised Windows installer

## English

The revised installer for Windows x64 manages local Node.js projects and trusted custom commands from one desktop app. It supports start/stop/restart, port checks, per-project logs, npm/pnpm/yarn/bun detection, optional autostart and bounded crash restart, an English/Arabic UI, and system tray controls. A custom command can run from a local folder without `package.json`; its port is optional for background workers. Install Node.js/npm for Node.js projects, or the appropriate runtime for a custom command.

Download `Local-Dev-Manager-Setup-1.0.0.exe` and compare its SHA-256 with `SHA256SUMS.txt` attached to this release. The installer may show a Windows SmartScreen warning because it has no established trusted code-signing reputation. Run only commands and projects you trust.

**Already installed v1.0.0?** Download and run this revised installer manually. The app's updater does not treat a different installer with the same `1.0.0` version number as a new update. `latest.yml` and the blockmap are included for the packaged update feed, but they do not make this same-version revision appear as an automatic update. The `v1.0.0` tag and GitHub-generated source archives still point to the original release; the revised source is on `main`.

## العربية

المثبّت المُحدَّث لـ Windows x64 يدير مشاريع Node.js المحلية والأوامر المخصصة الموثوقة من تطبيق واحد. يتيح التشغيل والإيقاف وإعادة التشغيل، فحص المنافذ، سجلات منفصلة، اكتشاف npm/pnpm/yarn/bun، التشغيل التلقائي وإعادة التشغيل المحدودة بعد الانهيار، واجهة عربية/إنجليزية، وصينية النظام. يمكن تشغيل أمر مخصص من مجلد محلي دون `package.json`، ويمكن ترك المنفذ فارغًا للعامل الخلفي. ثبّت Node.js/npm لمشاريع Node.js، أو بيئة التشغيل المناسبة للأمر المخصص.

نزّل `Local-Dev-Manager-Setup-1.0.0.exe` وقارن SHA-256 بملف `SHA256SUMS.txt` المرفق عند الحاجة. قد يظهر تحذير Windows SmartScreen لعدم وجود سمعة توقيع برمجي موثوقة بعد. لا تشغّل إلا مشاريع وأوامر تثق بها.

**هل ثبتَّ v1.0.0 سابقًا؟** نزّل هذا المثبّت المُحدَّث وشغّله لإعادة التثبيت يدويًا. لا يعتبر محدّث التطبيق مثبّتًا مختلفًا يحمل رقم `1.0.0` نفسه تحديثًا جديدًا. أُرفق `latest.yml` وملف blockmap لتغذية التحديثات، لكنهما لا يجعلان هذا البناء ذي الرقم نفسه تحديثًا تلقائيًا. ما زال وسم `v1.0.0` وأرشيف المصدر الذي يولده GitHub يشيران إلى الإصدار الأصلي؛ شيفرة المثبّت المُحدَّث في فرع `main`.

## 简体中文

修订版 Windows x64 安装包可在一个桌面应用中管理本地 Node.js 项目和可信自定义命令。它支持启动、停止、重启、端口检查、独立日志、npm/pnpm/yarn/bun 识别、可选自动启动和有限次数的崩溃重启、英语/阿拉伯语界面以及系统托盘。自定义命令可在没有 `package.json` 的本地目录运行；后台任务可以不设置端口。Node.js 项目需要 Node.js/npm，自定义命令需要自行安装相应运行环境。

下载 `Local-Dev-Manager-Setup-1.0.0.exe`，如需校验可对照本发布页的 `SHA256SUMS.txt`。由于安装包尚无成熟的可信代码签名信誉，Windows SmartScreen 可能显示警告。只运行可信的项目和命令。

**已安装旧版 v1.0.0？** 请下载修订版并手动重新安装。应用内更新器不会将版本号同为 `1.0.0` 的不同安装包识别为新更新。发布页包含供打包更新使用的 `latest.yml` 和 blockmap，但它们不会让此次同版本修订自动更新。`v1.0.0` 标签和 GitHub 自动生成的源码压缩包仍指向最初的发布版本；修订版源码位于 `main` 分支。
