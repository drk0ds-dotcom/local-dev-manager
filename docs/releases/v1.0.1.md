# Local Dev Manager v1.0.1 — draft release notes

> Local preparation only. The installer below has not yet passed its own installed-app upgrade check in Windows Sandbox. Do not publish these notes or the installer until the owner approves GitHub changes.

This Windows x64 patch release corrects process-stop status and failure recovery, detects a real listening port before showing `Running`, and protects saved projects when one entry is invalid. Trusted custom commands remain supported.

- `Stopping` remains visible until process exit is confirmed. A failed stop displays the PID and can be retried; quitting reports processes that remain alive. Removing a running project retains its saved entry, logs, and selected view if stopping fails, so Stop or Remove can be retried.
- Servers that print `Server started on PORT` can be detected even when they ignore the configured port. A live server that has not opened a detectable port shows a localized `Waiting for port PORT` badge and an explanatory log after 10 seconds; it is never marked `Running` solely because time elapsed.
- An invalid saved command or missing path makes the project list read-only without rewriting the original. A `.corrupt-*` copy is saved, the affected project is named, and Add Project explains why it cannot continue.

The planned installer is `Local-Dev-Manager-Setup-1.0.1.exe`. Its SHA-256 is `eb1e52ad0885d93bd85f07ebad8ad9e6fd5205a05fc4d989b8507d7d89a26c76`; compare the downloaded file against this digest.
